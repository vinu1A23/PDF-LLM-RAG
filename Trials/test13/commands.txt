Creating an Image from a Dockerfile:

    docker build -t my-image-name . - This command builds an image from the Dockerfile in the current directory and tags it with the name "my-image-name".
    docker build -f /path/to/Dockerfile -t my-image-name . - This command builds an image from a Dockerfile located at a specific path and tags it with the name "my-image-name".

Running a Container:

    docker run -it my-image-name - This command runs a new container from the image "my-image-name" in interactive mode.
    docker run -d my-image-name - This command runs a new container from the image "my-image-name" in detached mode.
    docker run -p 8080:80 my-image-name - This command runs a new container from the image "my-image-name" and maps port 8080 on the host machine to port 80 in the container.
    docker run --name my-container-name my-image-name - This command runs a new container from the image "my-image-name" and assigns it the name "my-container-name".

Managing Containers:

    docker ps - This command lists all running containers.
    docker ps -a - This command lists all containers, including stopped ones.
    docker stop my-container-name - This command stops a running container.
    docker rm my-container-name - This command removes a stopped container.
    docker logs my-container-name - This command displays the logs of a container.

Managing Images:

    docker images - This command lists all available images.
    docker rmi my-image-name - This command removes an image.
    docker tag my-image-name:latest my-image-name:v1 - This command tags an image with a new version number.

To give internet access to a Docker container while creating and starting it, you can use the following methods:

*   Use the `--net=host` flag when running the container. This flag allows the container to use the host's network stack, giving it access to the internet.

    ```bash
docker run -it --net=host my-image
```

*   Use the `--dns` flag to specify a DNS server for the container. This flag allows the container to resolve hostnames and access the internet.

    ```bash
docker run -it --dns 8.8.8.8 my-image
```

*   Use the `--net` flag with a bridge network. By default, Docker creates a bridge network that allows containers to communicate with each other and the host. You can specify this network when running the container.

    ```bash
docker run -it --net bridge my-image
```

*   Create a custom network and attach the container to it. This method gives you more control over the network configuration.

    ```bash
docker network create my-network
docker run -it --net my-network my-image
```

*   Use the `docker-compose` file to define the network configuration. This method is useful when working with multiple containers.

    ```yml
version: '3'
services:
  my-service:
    image: my-image
    networks:
      - my-network

networks:
  my-network:
    driver: bridge
```

    Then, run the container using `docker-compose up`.

*   If you're using Docker Desktop, you can also configure the network settings in the Docker Desktop preferences.

    Go to **Preferences** > **Resources** > **Network**, and select the network interface you want to use.

Note that the `--net=host` flag can have security implications, as it allows the container to access the host's network stack. Use this flag with caution and only when necessary.
